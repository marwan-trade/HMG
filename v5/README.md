# HMG Global Business Solutions — site web (branche principale)

Pages générées d'après le PDF « Site HMG Global Business Solutions — Maquettes » :
textes, schémas numérotés, listes et formulaires repris à l'identique, mise en page sobre du PDF.
Les informations entre crochets ([E-MAIL À CONFIRMER], [ADRESSE]…) sont volontairement visibles : à confirmer.

- Pages : index, logistique, sourcing, conseil, a-propos, contact, mentions-legales, merci
- Style : css/main.css · Images : assets/ · Scripts : js/i18n.js (FR/EN), js/forms.js
- Formulaires : envoi via FormSubmit (adresse de test)
